# V3 baseline result artifacts

The executed notebook writes the canonical derived tables as CSV files when run locally. The fork repository uses Git LFS for CSV paths, and GitHub browser upload cannot create/update LFS objects. Therefore, this directory publishes JSON review mirrors with the same rows and columns; the local CSV outputs remain generated by the notebook and are attached with the release materials.

The JSON mirrors are not modified or statistically transformed. They are direct serializations of the executed notebook outputs. The six static figures are published as PNG files in `plots/`. The validator checks the local CSV outputs, notebook execution, figures, metrics, and protected-input hashes.
